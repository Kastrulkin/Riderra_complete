## Root cause

Phone-based inbound routing filtered out every task in state closed before considering that a short acknowledgement can arrive seconds after the final Riderra message.

## Approved fix

Recognize a narrow set of standalone acknowledgements, attach one to the unique recently closed WhatsApp order dialog from the same phone within 24 hours, keep the dialog closed, and skip response-draft generation.

**Why this is causal:** The new fallback runs exactly where the active-task lookup previously failed and selects the proven original task before inquiry creation.
